FRAMER MOTION (Pilihan Utama Create)
──────────────────────────────────────
Install  : npm install framer-motion
Docs     : motion.dev/docs

Hook-hook penting:
- useScroll        → track posisi scroll (0-1)
- useTransform     → ubah nilai scroll jadi nilai animasi lain
- useInView        → deteksi elemen masuk viewport
- whileInView      → trigger animasi saat masuk viewport
- AnimatePresence  → animasi mount/unmount komponen
- staggerChildren  → delay bertahap antar child

Teknik animasi utama:
1. Scroll Reveal  → whileInView + viewport: {once:true}
2. Parallax       → useScroll + useTransform → translateY
3. Stagger Cards  → variants + staggerChildren: 0.1
4. Counter Anim   → useInView + useState + useEffect
5. Text Reveal    → split string per kata/char + stagger
6. Page Transition→ AnimatePresence + motion.div

Contoh scroll reveal:
<motion.div
  initial={{ y: 50, opacity: 0 }}
  whileInView={{ y: 0, opacity: 1 }}
  viewport={{ once: true, margin: "-100px" }}
  transition={{ duration: 0.6, ease: "easeOut" }}
>

Contoh parallax hero:
const { scrollY } = useScroll()
const y = useTransform(scrollY, [0, 500], [0, -150])
<motion.div style={{ y }}>Background Element</motion.div>

LENIS SMOOTH SCROLL
──────────────────────────────────────
Install  : npm install @studio-freight/lenis
Fungsi   : Membuat scroll native menjadi ultra-smooth
Cara pakai di Next.js:
1. Buat providers/LenisProvider.tsx
2. useEffect → init Lenis → requestAnimationFrame loop
3. Wrap app di layout.tsx dengan <LenisProvider>

GOOGLE MAPS — CARA EMBED
════════════════════════════════════════════════════════════════════

CARA TERMUDAH (Tanpa API Key — Gratis):
1. Buka maps.google.com
2. Cari nama bisnis / alamat
3. Klik Share (ikon share/bagikan)
4. Pilih tab "Embed a map"
5. Klik "Copy HTML"
6. Paste iframe ke komponen Location.tsx

Format iframe:
<iframe
  src="https://www.google.com/maps/embed?pb=!1m18!..."
  width="100%"
  height="400"
  style="border:0;"
  allowfullscreen=""
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade">
</iframe>

CARA DENGAN API KEY (Lebih Fleksibel):
1. Buka Google Cloud Console → Maps Embed API
2. Buat API key
3. Simpan di .env.local sebagai NEXT_PUBLIC_GOOGLE_MAPS_KEY
4. Format URL:
   https://www.google.com/maps/embed/v1/place
   ?key=YOUR_KEY&q=NAMA+BISNIS+KOTA&zoom=16

CATATAN: Maps Embed API gratis dengan unlimited request 
(perlu billing account tapi tidak dicharge untuk embed biasa)

Referensi resmi: developers.google.com/maps/documentation/embed

STANDAR KUALITAS ANIMASI
════════════════════════════════════════════════════════════════════

WAJIB ADA DI SETIAP WEBSITE:
✓ Smooth scroll (Lenis)
✓ Navbar scroll-aware (transparan → blur backdrop)
✓ Hero entrance animation (teks + CTA)
✓ Scroll reveal setiap section
✓ Hover effect pada semua card dan tombol
✓ Stagger animation pada list/grid
✓ WhatsApp button floating (mobile)
✓ Google Maps embed (jika ada lokasi fisik)

SANGAT DIREKOMENDASIKAN:
★ Parallax pada hero background
★ Counter animation untuk statistik
★ Loading screen singkat
★ Page transition
★ Text split animation untuk headline
★ Cursor custom (untuk brand premium)

HINDARI:
✗ Animasi yang terlalu cepat (< 200ms) atau lambat (> 1000ms)
✗ Terlalu banyak animasi bersamaan (max 3 elemen animasi sekaligus)
✗ Animasi yang menyebabkan layout shift
✗ Efek yang membuat mual di mobile (parallax berlebihan)
✗ Animasi yang menghalangi konten penting

PERFORMA TARGET:
- Google PageSpeed Score: 85+ (mobile), 95+ (desktop)
- Largest Contentful Paint: < 2.5 detik
- Cumulative Layout Shift: < 0.1
- First Input Delay: < 100ms

REFERENSI DESAIN PER NICHE
════════════════════════════════════════════════════════════════════

UMKM / TOKO LOKAL:
- Warna: warm tones (oranye, kuning keemasan, coklat krem)
- Style: friendly, approachable, tidak terlalu formal
- Font heading: Poppins atau Plus Jakarta Sans
- Font body: Inter atau Nunito
- Inspirasi: desain seperti brand lokal sukses (Fore Coffee, 
  Kopi Kenangan, Filosofi Kopi)

KLINIK / MEDIS:
- Warna: putih bersih, biru tenang, hijau mint, atau teal
- Style: profesional, bersih, menimbulkan kepercayaan
- Font: Raleway atau Montserrat (heading), Inter (body)
- Hindari: terlalu banyak merah/gelap
- Inspirasi: Halodoc website, KlikDokter

SEKOLAH / PENDIDIKAN:
- Warna: biru + kuning, atau hijau + putih
- Style: modern tapi ramah, memberi kesan akademik berkualitas
- Font: Nunito (ramah) atau Merriweather (akademik)
- Wajib ada: galeri kegiatan, info program, pendaftaran

RESTORAN / KULINER:
- Warna: merah hangat + krem, atau earth tone gelap
- Style: menggiurkan, appetizing, konten foto SANGAT penting
- Font: Playfair Display (elegan) atau Lobster (casual)
- Wajib ada: menu digital, foto makanan besar

SALON / BARBERSHOP:
- Warna: hitam + emas (barbershop premium), 
         rose gold + krem (salon wanita)
- Style: stylish, trendy, portofolio hasil kerja prominent
- Font: Cormorant Garamond atau Josefin Sans

BENGKEL:
- Warna: abu-abu metalik + oranye atau merah
- Style: maskulin, profesional, menimbulkan kepercayaan
- Font: Bebas Neue (heading), Roboto (body)

PROPERTI:
- Warna: navy + putih + gold, atau abu modern + teal
- Style: prestisius, luas, menampilkan kemewahan
- Font: Playfair Display atau Cormorant (heading)

HOTEL / VILLA:
- Warna: krem mewah + coklat tua + gold
- Style: premium, immersive, banyak foto berkualitas tinggi
- Font: Cormorant Garamond + Lato
